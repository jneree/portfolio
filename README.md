# julneree.com

Static portfolio site. No framework: `index.html` and the three article pages are generated by a small Python script, and everything in the repo is what gets served.

## Edit

- Copy, captions and image order: `build/content.py`
- Articles: `build/articles/<slug>.html` (plain HTML; `{{img:path|caption}}` and `{{video:path|caption}}` become optimised figures)
- Styles and behaviour: `assets/site.css`, `assets/site.js`

Then rebuild:

```bash
python3 -m venv .venv && .venv/bin/pip install pillow pillow-heif beautifulsoup4
brew install ffmpeg
.venv/bin/python build/build.py
```

Originals are read from `~/Downloads/julneree.com images` and `~/Downloads/julneree-concept-to-manufacturing`
(see `ROOTS` in `build/build.py`). Processed files in `img/` and `video/` are cached through
`build/manifest.json`, so only new or changed items need their original. `--force` re-encodes everything.

Preview locally:

```bash
python3 -m http.server 8765
```

## Deploy (GitHub Pages)

1. Repo settings → Pages → deploy from branch `main`, folder `/`.
2. Add a `CNAME` file containing `julneree.com`, then in the Bluehost DNS zone for julneree.com:
   - `A` records for `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` (replacing `76.76.21.21`)
   - `CNAME` for `www`: `jneree.github.io` (replacing `cname.super.so`)
3. Once the certificate is issued, tick "Enforce HTTPS", then cancel the Super.so site.

The old article URLs (`/4-key-lessons`, `/from-concept-phase-to-manufacturing`, `/ledger-nano-x`) keep working.
